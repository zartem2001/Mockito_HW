# Тестирование сервиса отправки сообщений (Mockito)

## 📋 Описание задачи

Дан сервис отправки локализованных сообщений. На основе IP-адреса, переданного 
в заголовке, определяется язык отправляемого сообщения:
- IP, начинающийся с `172.` → российский сегмент → **русский** текст.
- IP, начинающийся с `96.` → американский сегмент → **английский** текст.
- Все остальные IP → **английский** текст.

Необходимо написать unit-тесты с использованием **Mockito** для проверки 
корректности работы функционала.

## 🎯 Цель

Отработать:
- Написание unit-тестов с **Mockito**;
- Создание **заглушек (mock)** для зависимостей;
- Проверку поведения классов в изоляции;
- Использование `when(...).thenReturn(...)` и `verify(...)`.

## 🛠️ Используемые технологии

- Java 17+
- JUnit 5 (Jupiter)
- Mockito
- Maven
